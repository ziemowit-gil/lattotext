API konwertera wzorów

Jeden adres, odpowiedzi w JSON albo obrazek. Każdy użytkownik ma własny klucz (token). Każda odpowiedź ma też polski odczyt słowny wzoru dla czytników ekranu.

Adres

POST https://ziemowitgil.pl/latex/api.php

W przykładach token jest w zmiennej: export TOKEN=lx_…. Ten sam adres otwarty w przeglądarce pokazuje tę stronę. Programy, które nie proszą o HTML, dostają krótki opis w JSON.

Akcje

Dostępne akcje API
AkcjaWejścieOdpowiedź
to-latexJSON: input — wzór w zwykłym zapisie; opcjonalnie optionslatex, speech, errors
from-latexJSON: input — kod LaTeXtext, speech, errors
renderGET albo POST: input, from (latex lub text), format (svg lub png), opcjonalnie scale (1–8), color, backgroundobrazek wzoru; nagłówki X-Formula-Latex i X-Formula-Speech
scanmultipart: plik w polu plik (JPG, PNG, WEBP, GIF, PDF do 5 MB) albo JSON z media_type i data w base64latex, text, speech, warnings, mode. Pole only_math: 1 (domyślnie) — tylko wzory, tekst niematematyczny pominięty; 0 — cały dokument w LaTeX-u (wtedy text i speech są puste). Pole pages (tylko PDF): które strony odczytać, np. 1-3,5; bez pola — wszystkie. Odpowiedź ma wtedy pages_read i page_count

Opcje dla to-latex

mul: cdot, times albo none (znak mnożenia dla *), align: wyrównanie kolejnych linii do =, comma: polski przecinek dziesiętny.

Klucz API

Każde zapytanie wymaga tokenu użytkownika w nagłówku Authorization: Bearer lx_…. Token tworzysz po zalogowaniu na stronie Moje konto. Konta zakłada administrator, który może też wyłączyć dostęp do API wybranej osobie. Odczyty z kartki liczą się do Twojego dziennego limitu i trafiają do Twojej historii.

Linki GET do obrazków (?action=render…) muszą być podpisane. Podpisany link tworzy akcja sign z tymi samymi parametrami co render albo przycisk „Kopiuj link do obrazka” w kliencie HTTP.

Odczyt z kartki

Akcja scan wysyła obraz do Claude API (model Claude Opus 5.5), który przepisuje odręczne lub drukowane wzory do LaTeX-a. Odpowiedź może trwać do pół minuty. Bez konta obowiązuje dzienny limit odczytów na adres IP. Zarejestrowani użytkownicy mogą też wysyłać zdjęcia mailem.

Przykłady

Zwykły zapis → LaTeX

curl -s https://ziemowitgil.pl/latex/api.php \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"to-latex","input":"x = (-b +- sqrt(b^2-4ac))/(2a)"}'

LaTeX → zwykły zapis

jq -n --arg s '\frac{a}{b} + \sqrt{x}' '{action:"from-latex", input:$s}' \
  | curl -s https://ziemowitgil.pl/latex/api.php -H "Authorization: Bearer $TOKEN" \
      -H 'Content-Type: application/json' -d @-

Wzór → obrazek PNG lub SVG

curl -s https://ziemowitgil.pl/latex/api.php \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"render","input":"sqrt(x^2+y^2)","from":"text","format":"png","scale":4}' \
  -o wzor.png

Podpisany link do wstawienia jako <img src>:

curl -s https://ziemowitgil.pl/latex/api.php -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"sign","input":"a/b","from":"text","format":"svg"}'
# → {"url": "https://ziemowitgil.pl/latex/api.php?action=render&…&u=…&sig=…"}

Zdjęcie kartki → LaTeX

curl -s https://ziemowitgil.pl/latex/api.php \
  -H "Authorization: Bearer $TOKEN" -F action=scan -F plik=@kartka.jpg

Przykładowa odpowiedź

{
  "latex": "x = \\frac{-b \\pm \\sqrt{b^{2} - 4ac}}{2a}",
  "speech": "x równa się ułamek, licznik: minus b plus minus pierwiastek z …",
  "errors": []
}

Błędy

Błąd ma pole error z opisem po polsku. Błędy składni wzoru wracają w liście errors z numerem linii i znaku.

Kody odpowiedzi
KodZnaczenie
400Brakuje danych, zły JSON albo nieznana akcja.
401Brak tokenu, nieprawidłowy token, zablokowane konto albo niepodpisany link do obrazka.
403Administrator wyłączył dostęp do API dla tego konta.
413Plik ponad 5 MB albo tekst ponad 20 000 znaków.
415Nieobsługiwany format pliku. Zdjęcia HEIC zapisz jako JPG.
422Nie znaleziono wzoru albo nie da się go odczytać.
429Wykorzystany dzienny limit odczytów albo chwilowa blokada serwera.
503Odczyt z kartki jest wyłączony (brak klucza Claude API na serwerze).

Skrypt w Pythonie

Wysyłaj pliki z wiersza poleceń, bez przeglądarki. Skrypt potrzebuje tylko Pythona 3.8 lub nowszego, bez dodatkowych pakietów.

Pobierz latexconverter.py (9 KB)

export LATEX_TOKEN=lx_…            # token z Mojego konta
python latexconverter.py kartka.jpg            # zapyta: tylko wzory czy cały dokument
python latexconverter.py kartka.jpg --tylko-wzory
python latexconverter.py skrypt.pdf --tylko-wzory --strony 2-4
python latexconverter.py notatki.pdf --caly-dokument -o notatki.tex
python latexconverter.py wzory.txt             # zwykły zapis → LaTeX
python latexconverter.py wzor.tex              # LaTeX → zwykły zapis
python latexconverter.py wzory.txt --obrazek png -o wzor.png
python latexconverter.py --help                # wszystkie opcje

Skrypt rozpoznaje rodzaj pliku po rozszerzeniu: JPG, PNG, WEBP, GIF i PDF idą do odczytu przez AI, .tex do zamiany na zwykły zapis, pozostałe pliki tekstowe do zamiany na LaTeX.

Claude Code

Dodaj umiejętność, a Claude Code sam użyje tego API, gdy poprosisz o LaTeX dla wzoru, zamianę LaTeX-a albo przepisanie wzorów ze zdjęcia kartki:

mkdir -p ~/.claude/skills/rownania-latex
curl -so ~/.claude/skills/rownania-latex/SKILL.md https://ziemowitgil.pl/latex/SKILL.md

Opis dla modeli językowych: llms.txt. Treść umiejętności: SKILL.md.
